Axum

Axum is a new(the latest version in community is v0.8, but there are also many crates under 1.0) API framework based on tokio with excellent design. That is also why I choose axum rather than Rocket, actix or some other popular web framework. However, there also many voice complaining the breaking changes of Axum which I believe that would be changed v1.0 realeased.

Concepts

Routers

As you can see, just add your path, method type and handler. That’s easy, right?

Of course, we can define multiple API in the same path like

Handlers

There is an example that used to realize Snowflake External function.

The first thing is the parameters, in axum, they are called extractors which to extract different part in our HTTP request.

Extractors can be seen as several parts as follows:

  • Path related
    • Path parameter: parse id in /user/:id
    • Query parameter: parse ?a=1&b=2
  • Body related
    • Json
    • Bytes
    • String
  • Others
    • HeaderMap: headers
    • State<T>: shared state registered in router

Middleware

I use tower and tower-http as middleware layer in my program.
