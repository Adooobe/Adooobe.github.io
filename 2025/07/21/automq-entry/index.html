从源码可以看出，AutoMQ 在 Controller 启动过程中添加了：

  • StreamClient: 用于云原生存储访问
  • ElasticControllerApis: 替代标准的 ControllerApis
  • 命名空间设置: ObjectUtils.setNamespace(Constants.DEFAULT_NAMESPACE + clusterId)
  • AutoBalancerManager: 自动均衡管理器

启动流程总结

Controller 的启动是一个严格按序的过程：

  1. 状态管理 → 监控指标 → 权限认证 → 网络通信
  2. SharedServer启动 → 策略配置 → 核心控制器构建
  3. API处理器 → 元数据发布器 → 网络服务启动
  4. 整个过程确保了元数据的一致性和控制器的高可用性
